# DraftLister — Motion-First design preview

A standalone visual prototype. All listing outputs and generation progress are clearly labeled illustrative. No AI requests, payments, licensing, quota or database integration.

- `index.html`: newest interactive preview
- `compare.html`: previous/new comparison, desktop/mobile
- `notes.html`: sources, license findings and acceptance checklist

## Hosting
Enable GitHub Pages from the `main` branch, root directory. No build step or paid hosting required.
