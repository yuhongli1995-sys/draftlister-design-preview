V3 / V2 comparison

Hybrid V3 — usability first

  • Independent editable title and description per platform. Copy either field or the complete listing. Edits survive switching platforms and showing samples again, until refresh.
  • Four-photo local upload with format/size/decode checks, removal and keyboard-accessible reorder buttons.
  • Prominent Start Listing; shorter story; mobile results focus and View Drafts link.
  • Larger interactive text, keyboard tabs, focus styles, system reduced-motion support.
  • Optional advanced details; concise how-it-works, pricing and privacy links, FAQ.
  • Result cards unfold on showing samples, then open an editable draft. No simulated AI loading.

Known boundaries

This is a demo, not a live AI tool. Uploaded photos, notes and advanced fields do not affect the fixed jeans examples. Edits and photos are not persisted beyond this tab. No production deployment, API/payment/credit/database/pricing changes. Real generation remains dependent on access to the actual product repository and its authorized integration; use the live product for real generation.

Photo processing failures, platform validation and clipboard failures are handled locally. Real mobile devices, OS-level reduced-motion, and production end-to-end generation require further testing.
